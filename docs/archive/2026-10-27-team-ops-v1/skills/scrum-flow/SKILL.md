# Scrum Flow

Use for product work with changing requirements.

Prose: Product Owner, Scrum Master, Developers; Planning, Daily, Review, Retro. Ranked backlog, pull by capacity, demo each sprint, one retro fix. Sprint Backlog is the implicit WIP limit.

Logic:
- require backlog with ranks exists
- plan sprint by capacity, never by wish
- review demo plus retro action
- return sprint plan plus retro item
