# ADR shape

Use when an ADR is warranted; follow the repo's existing format first. This shape retains MADR context, drivers, credible options, decision, and consequences.

```markdown
# NNNN. <decision as a short imperative phrase>
- Status: proposed | accepted | rejected | deprecated | superseded by NNNN
- Date: YYYY-MM-DD
- Deciders: <approver>, <contributors>

## Context and problem
## Decision drivers
## Options considered
1. <option A>: pros / cons
2. <option B>: pros / cons
## Decision
Chosen: <option>, because <justification tied to drivers>.
## Consequences
- Good / Bad (accepted trade-offs) / Follow-ups and revisit trigger
```
