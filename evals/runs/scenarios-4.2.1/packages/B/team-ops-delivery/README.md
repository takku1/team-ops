# team-ops-delivery

Specialist playbooks for test and CI policy, releases, SLOs, incidents, and forecasting. Load only the playbook relevant to the requested work. This package preserves adopted project policy and existing authorization; its example thresholds do not silently become local requirements.

The core team-ops plugin is useful but not mandatory. If a referenced core playbook is unavailable, perform the applicable work inline using [host fallbacks](references/host-compatibility.md). The packaged [evidence register](references/research-evidence.md) distinguishes empirical research, practitioner guidance, standards, and adjustable suite defaults.
