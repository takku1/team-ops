A successful answer does not accept: a report with the worker's own job still running and predicted rather than observed results is not evidence. It has the worker finish or hand back the job (or the lead collects its output), requires the actual command, exit status, and input identity for the current artifact, and keeps the task open until then. Fails if it accepts, or treats 'should pass' as passing.
